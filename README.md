# MEDBIKESI

Двуязычный сайт частной медсестры и практического курса сестринских навыков в Астане.

- Продакшен: [www.medbikesi.kz](https://www.medbikesi.kz/)
- Хостинг: Vercel
- Стек: семантический HTML, CSS и vanilla JavaScript без сборки и runtime-зависимостей
- Языки: русский и казахский

## Структура проекта

```text
site/index.html          главная страница услуг на дому
site/kursy.html          отдельный лендинг офлайн-курса
site/policy.html         политика конфиденциальности
site/css/style.css       дизайн-система и адаптивные стили
site/js/config.js        контакты, цены, параметры курса и ID аналитики
site/js/content.js       услуги, FAQ, программа и подтверждённые факты
site/js/i18n.js          интерфейсные тексты RU/ҚАЗ
site/js/main.js          интерактив, формы, переключение языка и аналитика
site/robots.txt          правила индексации
site/sitemap.xml         карта сайта для Google Search Console
docs/UX_AUDIT.md         UX-аудит и новая информационная архитектура
docs/TZ.md               актуальное техническое задание
DESIGN_SYSTEM.md         токены и правила визуальной системы
DESIGN_REFERENCES.md     исследование визуального направления
```

## Локальный запуск

```bash
python3 -m http.server 4173 -d site
```

После запуска открыть `http://127.0.0.1:4173/`.

Сборщик не нужен: Vercel публикует каталог `site/`, указанный в `vercel.json`.

## Где менять данные

Все контакты и коммерческие параметры находятся в `site/js/config.js`.

```js
window.CONFIG = {
  phone: "+7 775 778 64 83",
  phoneDigits: "77757786483",
  formKey: "",
  prices: { /* подтверждённые цены */ },
  course: { /* цена, длительность и формат */ },
  analytics: { /* GA4 и Google Ads */ }
};
```

- Пустая цена отображается честно как «Стоимость уточняется».
- Пока `formKey` пустой, форма не теряет заявку: она открывает WhatsApp с подготовленным сообщением.
- После добавления ключа Web3Forms форма сможет отправлять обращение на электронную почту.
- Google Analytics и Google Ads не загружаются, пока их ID не заполнены.
- Noto Sans и Noto Serif Display хранятся локально в оптимизированных WOFF2-сабсетах; сайт не ждёт Google Fonts.

Тексты услуг, программы и FAQ редактируются в `site/js/content.js`; интерфейсные переводы — в `site/js/i18n.js`.

## SEO и индексация

- Канонический адрес: `https://www.medbikesi.kz/`
- Sitemap: `https://www.medbikesi.kz/sitemap.xml`
- Robots: `https://www.medbikesi.kz/robots.txt`
- В HTML настроены уникальные title/description, Open Graph, семантические заголовки и консервативная schema.org-разметка без выдуманных рейтингов.

После публикации sitemap отправляется в Google Search Console как `sitemap.xml`. Сам файл `robots.txt` отдельно загружать в Search Console не нужно.

## Формы и аналитика

Основная конверсия — WhatsApp, вторичная — звонок, затем форма. Подготовлены события:

- клики WhatsApp и телефона;
- выбор услуги и категории;
- открытие деталей услуги;
- запрос стоимости;
- вопросы и запись на курс;
- отправка формы.

Для боевого отслеживания нужно получить GA4 Measurement ID, Google Ads ID и conversion labels, затем заполнить `CONFIG.analytics`.

## Публикация

Изменения в ветке `main` автоматически разворачиваются Vercel. DNS основного домена и `www` настроены в PS.kz.

Перед запуском рекламы владелец должен подтвердить медицинские и юридические формулировки, особенно услугу вывода из запоя, право оказания услуг и рекламные ограничения Google Ads.
