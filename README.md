# Сайт «Медсестра на дом» — Астана

Статический сайт для частной медсестры. Без сборки, без зависимостей:
HTML + CSS + чистый JS. Открывается двойным кликом по `site/index.html`.

## Что где

```
docs/TZ.md              техническое задание (согласовать с заказчиком)
site/index.html         главная — услуги на дому
site/kursy.html         курсы медсестры / медбрата
site/policy.html        политика обработки персональных данных
site/css/style.css      все стили
site/js/config.js       ← ЕДИНСТВЕННЫЙ файл, который нужно заполнить
site/js/i18n.js         казахская версия текстов
site/js/main.js         интерактив
tools/build-preview.py  собирает всё в один файл для превью по ссылке
build/preview.html      результат сборки
```

## Перед запуском — заполнить `site/js/config.js`

1. **`phone` и `phoneDigits`** — на них ведут все кнопки звонка и WhatsApp.
   `phoneDigits` только цифры, без плюса: `77071234567`.
2. **`prices`** — цены по услугам. Пустая строка показывает «по запросу»,
   так что сайт работает и без них, но с ценами конверсия заметно выше.
3. **`course.price`, `course.duration`, `course.format`** — по курсам.
4. **`districts`** — районы выезда.
5. **`formKey`** — бесплатный ключ с [web3forms.com](https://web3forms.com),
   заявки будут приходить на почту. Пока ключа нет, форма открывает WhatsApp
   с уже заполненным текстом — это рабочий вариант, можно оставить.

Пример заполнения цен:

```js
prices: {
  im: "3000", iv: "5000", sc: "3000", drip: "9000", butterfly: "10000",
  detox: "25000", detoxFull: "35000", enema: "6000", catheter: "8000",
  dressing: "5000", trip: "1500", night: "2000", course5: "10"
}
```

## Дизайн

Концепция — **«Дежурство»**: после заголовка самый крупный элемент страницы это
номер телефона, набранный крупно на тёмной полосе рядом с индикатором «сейчас
на связи» и текущим временем Астаны. Расчёт на то, что человек заходит в тревоге
и часто ночью.

Три гарнитуры с полной поддержкой казахских букв: **Literata** (заголовки, номер,
цитаты), **Onest** (интерфейс и текст), **IBM Plex Mono** (цифры и подписи).
Палитра — хвойный `#14564A` на костяном `#EDF0E9`, тёмные полосы `#0C1A16`,
акцент срочности `#BF4527` только на блоке вывода из запоя и ночном выезде.

Между крупными блоками — тонкая полоса-разделитель с мотивом казахского
войлочного шва. Используется три раза на страницу, не чаще.

Ночная смена на сайте указана как **20:00–08:00** — и в русской, и в казахской
версии, включая калькулятор, прайс и блок вопросов.

## Языки

Русская версия лежит прямо в HTML, казахская — в `site/js/i18n.js`.
Чтобы поправить текст, найдите его ключ в атрибуте `data-i18n` и правьте
в обоих местах.

Страница курсов открывается на казахском по умолчанию (`data-default-lang="kz"`
на теге `<html>`). Плашка «Оқыту толығымен қазақ тілінде жүргізіледі» и её
русский перевод показываются **всегда, в обеих версиях** — это отдельное
требование заказчика, снимать её нельзя.

## Локальный просмотр

```bash
python3 -m http.server 4321 --directory site
```

## Превью одной ссылкой

```bash
python3 tools/build-preview.py
```

Собирает `build/preview.html` — самодостаточный файл со всеми тремя
страницами. Переходы между ними через `#/home`, `#/kursy`, `#/policy`.
Удобно, чтобы показать заказчику до покупки домена.

## Публикация

Хостинг: Netlify или Vercel, бесплатный тариф с HTTPS.
Перетащить папку `site/` в [app.netlify.com/drop](https://app.netlify.com/drop) —
сайт поднимется за минуту. Домен покупает и оформляет на себя заказчик.

Перед публикацией на боевом домене заменить `https://example.kz/` на реальный
адрес в: `site/index.html` и `site/kursy.html` (теги `canonical`, `og:` и
блоки JSON-LD), `site/robots.txt`, `site/sitemap.xml`.

## Что осталось получить от заказчика

Полный список — в разделе 14 файла `docs/TZ.md`. Блокирующее: имя,
номер телефона, цены. Остальное (фото, отзывы, сертификаты) можно досылать
после запуска.

Отзывы на сайте сейчас — заглушки, и об этом честно написано под блоком.
Заменить на реальные скриншоты из WhatsApp при первой возможности.
