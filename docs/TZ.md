# Техническое задание
## Сайт «Медсестра на дом» — Астана

**Версия:** 1.0
**Дата:** 27.08.2026
**Исполнитель:** Ақәділ (веб-разработка, Астана)
**Заказчик:** частная медсестра, стаж 18 лет, г. Астана

---

## 1. О проекте

Одностраничный сайт-визитка (landing page) с продающей структурой для частной
медицинской сестры, оказывающей услуги на дому в Астане. Дополнительное
направление — обучающие курсы медсестры/медбрата.

Сайт создаётся под платный трафик (Google Ads) + органический поиск Google.
Главная задача — не «красивая страница», а **заявка**: звонок, WhatsApp или
отправленная форма.

### Ключевая метрика
Конверсия «посетитель → обращение» (клик по WhatsApp / клик по номеру /
отправка формы). Цель — не ниже 6–8% на мобильном трафике.

## 2. Целевая аудитория

| Сегмент | Кто | Что ищет | Как решает |
|---|---|---|---|
| A. Уход за пожилым/лежачим | Взрослые дети 30–55 лет | «медсестра на дом Астана», «уколы на дом» | Ищут с телефона, звонят сразу |
| B. Курс лечения по назначению врача | Пациенты 25–60 лет | «капельница на дом», «система на дом» | Сравнивают цену, пишут в WhatsApp |
| C. Вывод из запоя | Родственники, чаще ночью/в выходные | «вывод из запоя на дому Астана» | Максимально срочно, анонимно, звонок |
| D. Перевязки после операции | Пациенты после стационара | «перевязка на дому» | Нужна регулярность, спрашивают про абонемент |
| E. Курсы медсестры | 18–40 лет, вход в профессию | «курсы медсестры Астана», «курсы медбрата» | Другой интент → отдельная страница |

**Вывод:** 80%+ трафика — мобильный, часто в состоянии стресса и спешки.
Отсюда все решения по дизайну: крупные кнопки, телефон в шапке, липкая нижняя
панель на мобильном, минимум текста до первого CTA.

## 5. Дизайн

### 5.1 Концепция
**«Дежурство».** Человек попадает на сайт в тревоге, часто ночью. Поэтому после
заголовка самый крупный элемент страницы — **номер телефона**: он набран
крупным шрифтом на тёмной полосе сразу под первым экраном, рядом с индикатором
«сейчас на связи» и текущим временем Астаны.

Спокойный, документальный тон вместо кричащей рекламы. Никаких стоковых
улыбающихся врачей: страницу держат типографика, воздух и тонкие линии.

### 5.2 Палитра
| Роль | Цвет | Применение |
|---|---|---|
| Основной | Глубокий хвойный `#14564A` | Кнопки, акценты, вторая строка заголовка |
| Фон | Тёплый костяной с зелёным подтоном `#EDF0E9` | Основной фон, с еле заметным зерном |
| Чередующийся фон | `#E4E9DF` | Секции через одну, для ритма |
| Текст | Зелёно-чёрный `#0F1D18` | Заголовки и основной текст |
| Тёмные полосы | `#0C1A16` | Дежурство, блок «Вывод из запоя», подвал |
| Акцент срочности | `#BF4527` | Только «Вывод из запоя» и ночной выезд |
| WhatsApp | `#25D366` | Только кнопки WhatsApp |

Серый намеренно уведён в зелёный подтон — иначе интерфейс читается как
неотредактированный шаблон.

Красный медицинский крест **не используем** — ассоциация со скорой помощью и
юридические ограничения на символику Красного Креста.

### 5.3 Типографика
Три гарнитуры, у каждой своя роль. Все три полностью поддерживают казахские
буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) — это проверялось отдельно.

| Роль | Гарнитура | Где |
|---|---|---|
| Заголовки, номер телефона, цитаты | **Literata** | H1–H3, крупные числа |
| Интерфейс и основной текст | **Onest** | Абзацы, кнопки, подписи |
| Цифры и служебные подписи | **IBM Plex Mono** | Цены, время, нумерация разделов |

- Заголовок H1: до 86 px на десктопе, 38–44 px на телефоне.
- Основной текст 17 px, межстрочный 1.58 — среди читателей есть пожилые люди.
- Минимальный кегль на сайте — 14 px, и только для служебных подписей.

### 5.4 Орнамент
Между крупными блоками — тонкая полоса-разделитель с геометрическим мотивом
казахского войлочного шва (ромб между отрезками). Используется сдержанно,
три раза на страницу, в цвет линий. Это привязывает сайт к месту, не скатываясь
в декоративность.

### 5.4 Тёмная тема
Поддерживается: сайт уважает системную тему пользователя (`prefers-color-scheme`)
плюс переключатель в шапке.

## 6. Интерактивность

Анимация — только функциональная, ничего декоративного ради декора.

1. **Sticky-шапка** — сжимается при скролле, появляется прогресс-бар прочтения.
2. **Появление секций** при скролле (fade + сдвиг 16 px, 400 мс).
3. **Карточки услуг** — раскрываются по клику: подробности, подготовка, длительность.
4. **Калькулятор стоимости** — выбор услуги + количество дней + район → примерная
   сумма и кнопка «Отправить расчёт в WhatsApp» с уже подставленным текстом.
5. **FAQ-аккордеон** — плавное раскрытие, открыт только один пункт.
6. **Слайдер отзывов** — свайп на мобильном, стрелки на десктопе, автопрокрутка
   с паузой при наведении.
7. **Форма** — валидация в реальном времени, маска телефона `+7 (7__) ___-__-__`,
   состояние загрузки, экран «Спасибо» без перезагрузки страницы.
8. **Мобильная нижняя панель** — «Позвонить» и «WhatsApp», появляется после
   первого экрана.
9. **Кнопка WhatsApp** — открывает чат с готовым текстом:
   `Здравствуйте! Пишу с сайта. Нужна услуга: {название}`.
10. **Счётчики** (18 лет стажа, 5000+ процедур) — анимация чисел при попадании в
    зону видимости.
11. **Плавная прокрутка** к якорям, подсветка активного пункта меню.

**Доступность:** все анимации отключаются при `prefers-reduced-motion: reduce`.
Фокус видим с клавиатуры, контраст текста не ниже AA (4.5:1), все интерактивные
элементы не меньше 44×44 px.

## 8. Технические требования

### 8.1 Стек
Статический сайт: HTML5 + CSS3 + чистый JavaScript, без фреймворков и без сборки.
Причина: сайт на 2 страницы, ему нужна максимальная скорость, простой хостинг и
возможность править контент без пересборки проекта.

### 8.2 Производительность (цели)
- Google PageSpeed Insights: **90+ на мобильном**
- Largest Contentful Paint: < 2.5 с на 4G
- Cumulative Layout Shift: < 0.1
- Вес первого экрана: < 500 КБ

Средства: изображения в WebP с `width`/`height`, `loading="lazy"` для всего ниже
первого экрана, критический CSS встроен, шрифт с `font-display: swap`,
JavaScript отложен (`defer`).

### 8.3 Браузеры
Chrome, Safari, Firefox, Edge — 2 последние версии. Safari на iOS 15+.

### 8.4 Формы и приём заявок
Основной канал — WhatsApp. Форма как запасной канал:
- Приём через сервис форм (Formspree / Web3Forms) → письмо на почту заказчика.
- Дублирование заявки в Telegram-бот — по желанию заказчика.
- Защита от спама: honeypot-поле + ограничение частоты отправки.
- Обязательная галочка согласия на обработку персональных данных.

### 8.5 Хостинг и домен
- Хостинг: Netlify или Vercel (бесплатный тариф, HTTPS, CDN) либо любой
  KZ-хостинг по желанию заказчика.
- Домен: латиницей, в зоне `.kz`, например `medsestranadom.kz`,
  `medsestra-astana.kz`, `uhod-astana.kz`. Проверка занятости — при согласовании.
- **Домен и хостинг оплачивает заказчик отдельно и оформляет на своё имя.**

## 9. SEO (базовая настройка — входит в стоимость)

- Уникальные `title` и `description` для обеих страниц.
- Семантическая разметка: один `H1` на страницу, корректная иерархия заголовков.
- Ключевые запросы (Астана): *медсестра на дом, уколы на дом, капельница на дому,
  система на дом, вывод из запоя на дому, перевязка на дому, установка катетера,
  курсы медсестры, курсы медбрата*.
- Микроразметка Schema.org: `LocalBusiness` + `MedicalBusiness`, `Service`, `FAQPage`,
  `AggregateRating` (после появления отзывов).
- Open Graph и Twitter Card — красивое превью при отправке ссылки в WhatsApp.
- `robots.txt`, `sitemap.xml`, канонические ссылки.
- `alt` у всех изображений.
- Подключение Google Search Console + Google Business Profile (карточка организации
  на Google Картах — бесплатный источник заявок, настоятельно рекомендуется).

**Не входит:** продвижение в топ, закупка ссылок, ведение SEO помесячно.
