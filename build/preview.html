    Политика конфиденциальности

    Какие данные получает MEDBIKESI, зачем они нужны и как связаться по вопросам их обработки.

    1. Какие данные обрабатываются

    Сайт получает только данные, которые пользователь вводит сам: имя, телефон, выбранную услугу или тему курса и комментарий. При переходе в WhatsApp сообщение передаётся только после того, как пользователь нажмёт «Отправить» в приложении.

    2. Для чего нужны данные

    Данные используются, чтобы ответить на обращение, уточнить назначение, адрес, время, стоимость услуги или условия обучения. Они не используются для постановки диагноза через сайт.

    3. Сторонние сервисы

    Сайт размещён на Vercel. Для связи используется WhatsApp. Если владелец подключит форму Web3Forms или аналитику Google, соответствующие сервисы будут обрабатывать технические данные по собственным политикам. Данные не продаются и не публикуются.

    4. Срок хранения

    Данные хранятся столько, сколько необходимо для ответа и оказания выбранной услуги, а также в пределах требований законодательства Республики Казахстан. Пользователь может запросить удаление данных.

    5. Права пользователя

    Можно запросить доступ, исправление или удаление своих данных, а также отозвать согласие на их обработку. Для этого позвоните или напишите по номеру, указанному на сайте.

    6. Локальные настройки и аналитика

    По умолчанию сайт сохраняет на устройстве только выбранный язык. Идентификаторы Google Analytics и Google Ads в текущей конфигурации не заполнены; аналитические данные не отправляются, пока эти сервисы не будут отдельно настроены.

    7. Медицинская оговорка

    Процедуры выполняются по назначению лечащего врача. Сайт носит информационный характер, не ставит диагнозы и не назначает лечение. При угрожающем жизни состоянии вызывайте скорую помощь по номеру 103.
